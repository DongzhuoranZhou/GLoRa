\chapter{Explanations of Long-Range Failure}

Message passing gives a graph neural network a route through which graph structure can affect a prediction.
At each layer, a node combines its previous-layer representation with messages from neighbouring nodes.
After one layer, the target node can use information from its immediate neighbours; after two layers, it can use information from nodes two hops away.
In the idealised picture, $d$ message-passing layers are enough for source information at graph distance $d$ to affect the target node.

Reachability, however, is only the first condition.
A trained model must preserve the relevant source information through successive message-passing layers and keep it separate from irrelevant information in fixed-dimensional node representations.
Training must also send enough gradient signal to the early layers where the source information is first processed.
Failure in any of these requirements can cause accuracy to fall as the dependency length $d$ increases.

The literature commonly explains such drops through three mechanisms: over-smoothing, over-squashing, and vanishing gradients \cite{li2018deeper,alon2021bottleneck,glorot2010difficulty}.
Each mechanism predicts a different internal trace.
Over-smoothing predicts that node representations converge until they can no longer support the prediction.
Over-squashing predicts that a bottleneck compresses too much relevant information into a fixed-size representation or through a narrow part of the graph.
Vanishing gradients predict that the loss sends too little training signal to the early message-passing layers that must learn what to preserve.
All three mechanisms are plausible in deep message-passing models, and each has motivated architectural changes in graph learning \cite{zhou2025glora}.

This chapter uses these predicted traces to organise the candidate explanations.
The GLoRa paper provides a controlled setting because the dependency length $d$ is fixed by construction, the intended dependency is expressible by standard message-passing systems, and the model has enough layers for source information to affect the target node \cite{zhou2025glora}.
After observing that many systems fail as $d$ grows, GLoRa asks whether the failing runs contain the trace predicted by each mechanism.
Its diagnostics do not support treating any of the three mechanisms as a complete explanation in the tested setting.
The conclusion is deliberately narrow: the accuracy drop identifies a failure to learn the dependency, while the internal trace provides evidence for assessing a candidate explanation of that failure.

\section{What a Candidate Explanation Must Explain}

A candidate explanation for long-range failure must connect the model's behaviour to a mechanism that makes source information unusable at the target node.
A long-range task is hard when the correct target-node prediction depends on source information that must survive a sequence of message-passing layers, not merely because two nodes are far apart in graph distance.
The graph must make the source node reachable from the target node, and the learned computation must use the source information once it is reachable.
Graph distance measures structural separation between the source and target nodes, whereas dependency length $d$ describes what the target function requires; a diagnosis concerns what happens inside the learned computation.

Each candidate explanation therefore needs its own evidence standard.
For over-smoothing, the relevant trace is convergence between node representations that should remain distinguishable.
For over-squashing, it is the loss of relevant source information as a graph or representational bottleneck compresses it.
For vanishing gradients, it is a backward signal that becomes too small in the message-passing layers that first process the source information.
An explanation must identify how its trace changes as $d$ increases and why that change prevents the target node from using the source information.

This standard matters because increasing $d$ changes several aspects of the problem at once.
The source node moves farther from the target node, and the model often needs more message-passing layers to receive its information.
The source information passes through more intermediate updates, while the messages arriving at the target node can change in distribution.
The deeper learned computation can also change the optimization problem.
The accuracy curve identifies the failing runs, but only a mechanism-specific trace can distinguish among these effects.

GLoRa follows this sequence explicitly.
It constructs benchmarks whose intended solution requires source information at dependency length $d$, evaluates graph learning systems as $d$ increases, and then tests the internal traces predicted by the common explanations \cite{zhou2025glora}.
The following sections apply that sequence to each mechanism in turn: first the mechanism, then its evidence standard, and finally the GLoRa interpretation.

\section{Over-Smoothing}

Over-smoothing predicts a representation trace in which node representations that should remain distinct converge towards similar values.
Many graph neural networks update each node by mixing its current representation with messages from neighbouring nodes.
Repeated mixing can erase distinctions that the final classifier needs for node classification \cite{li2018deeper}.
The corresponding GLoRa question is whether the accuracy drop at larger $d$ is accompanied by collapse in the target node representations.

This explanation is plausible in a long-range task because depth has two roles.
The target node needs enough message-passing layers to receive source information from graph distance $d$, but those layers also continue to mix representations across the graph.
The depth that makes the source information reachable can therefore make relevant representations less distinguishable.
For over-smoothing to explain the failure, however, this repeated mixing must produce representation convergence.

Consider two examples that require different labels because their source information differs.
If message passing preserves that distinction, their final target node representations should differ in a way that the classifier can use.
Under over-smoothing, those representations move towards the same value, so the classifier receives nearly identical inputs for examples that require different outputs.
The model may then have sufficient depth in graph-distance terms even though the source information is no longer usable for the target-node prediction.

The direct evidence for over-smoothing should therefore come from node representations.
For node classification, the most relevant quantity is the final target node representation before the classifier.
A diagnostic should test whether representations for examples with different labels converge as the number of message-passing layers or the dependency length $d$ grows.
Convergence that appears before the classifier and becomes more severe at larger $d$ would support the explanation.

Supporting diagnostics can measure representation variance across nodes or examples, compare distances between target node representations for different labels, or test whether methods designed to prevent collapse restore both separation and accuracy.
These measurements all address the same predicted trace: representations that should remain different have become too similar.

GLoRa checks this trace directly after first establishing that accuracy drops as $d$ increases for many systems.
The paper inspects last-layer target node representations for the best-performing systems at a short dependency length where accuracy is perfect and at a longer dependency length where accuracy is close to random guessing.
At the short dependency length, representations for the two labels are clearly separated.
At the longer dependency length, they are more mixed, as expected from the poor accuracy, but they do not collapse to a single value and their standard deviation remains substantial \cite{zhou2025glora}.

For the inspected systems in the tested GLoRa setting, the observed degradation therefore lacks the representation convergence predicted by over-smoothing.
The increased mixing is consistent with poor classification, but it is not the same as collapse to indistinguishable representations.
This result does not exclude over-smoothing in other settings or under other measurements.
It limits the GLoRa conclusion to the trace that was inspected: final target node representations do not show the simple collapse needed for over-smoothing to explain these failures.

\section{Over-Squashing}

Over-squashing predicts a compression trace in which a channel is too narrow to carry all relevant source information.
A node representation has fixed dimension even when the amount of information that could influence the target node grows.
If many distant nodes can affect the target node, the model may have to compress their information through a small set of intermediate nodes or edges.
The corresponding GLoRa question is whether longer source-to-target paths create the bottleneck needed to explain the drop.

The mechanism is most natural on graphs with structural bottlenecks.
If a target node's label can depend on one source node among many distant nodes, and their influence must cross a narrow graph cut, intermediate representations must encode a large amount of information.
Increasing $d$ can intensify this pressure when the number of possible source nodes or directed paths to the target node grows quickly.
The source node can remain reachable even when the relevant source information does not fit through the available representational channel.

This mechanism differs from over-smoothing.
Over-smoothing makes representations too similar through repeated mixing, whereas over-squashing packs too much distinct information into bounded space.
A model can therefore suffer from over-squashing without its node representations converging.
The target node representation may retain substantial variation while losing the particular source information needed for the label.

Evidence for over-squashing should establish the bottleneck and connect it to information loss.
A structural diagnostic can test whether many directed paths, or many possible placements of the relevant source node, must pass through a small graph cut before reaching the target node.
A representational diagnostic can test whether increasing representation width improves the use of source information at large graph distance.
A graph intervention can test whether reducing the bottleneck improves performance while keeping the intended dependency comparable.
In each case, the evidence must tie the failure to compression between the source information and the target node.

This mechanism has motivated methods that change message passing or the graph.
Some add, remove, or reweight edges to provide shorter or less congested paths, while others use broader attention patterns, positional information, or rewiring rules that reduce pressure on narrow graph cuts.
The GLoRa paper groups several evaluated systems according to whether they target over-squashing or related gradient-flow problems \cite{zhou2025glora}.
Their performance tests whether interventions motivated by the bottleneck account improve long-range learning.

The main directed GLoRa construction does not create the path growth required by one common bottleneck account.
Each example has a bounded number of additional chains, at most $10$, and this bound does not grow with $d$.
The number of directed paths leading to the target node is therefore small and independent of the dependency length.
The paper argues that this rules out the particular over-squashing story in which an exponential number of directed source-to-target paths is compressed into the target node representation \cite{zhou2025glora}.

Directedness is essential to this argument.
If the same chain were treated as undirected, message passing could use both edge directions.
As the number of message-passing layers grew, even a simple chain could then generate many possible walks ending at the target node.
The bounded-directed-path argument would no longer apply, as the paper explicitly notes \cite{zhou2025glora}.

GLoRa thus tests a specific structural form of over-squashing rather than every possible loss of information.
The source node is far from the target node, but distance alone does not create congestion.
In the main directed benchmarks, the path structure does not supply the predicted exponential pressure, yet the failure remains.
This result shows that the tested bottleneck account is not a complete explanation for the observed degradation; it does not universally exclude other forms of compression.

\section{Vanishing Gradients}

Vanishing gradients predict an optimization trace in which the backward signal becomes too weak in the early layers that must learn how to process source information.
They occur when the gradient of the loss becomes very small as it is backpropagated through a deep computation.
If the gradient reaching the early message-passing layers is close to zero, those layers may not learn how to process the source information before later layers propagate it towards the target node.
The corresponding GLoRa question is whether failures at larger $d$ are accompanied by this weak backward signal.

The mechanism is not specific to graphs.
Backpropagation uses the chain rule, and a product of many derivatives can become very small.
Early parameters then receive weak updates, so the relevant parts of a deep computation may train slowly or stop improving \cite{glorot2010difficulty}.

In a graph neural network, this optimization problem follows the message-passing path.
For a dependency of length $d$, source information must be processed and propagated through successive layers before it affects the target node prediction.
The gradient of the output loss must travel backwards through the classifier, the target node updates, and the intermediate message-passing layers.
If that signal decays with depth, the forward computation can make the source node reachable without teaching the model to preserve its information.

Evidence for vanishing gradients should therefore come from training dynamics.
A direct diagnostic measures gradient norms in early layers as the dependency length $d$ or the number of message-passing layers increases.
The explanation becomes plausible if early-layer gradients shrink towards zero in failing settings but not in successful shorter settings.
One can also test whether techniques known to improve gradient flow restore both gradient magnitude and task accuracy, including residual connections, normalization, careful initialization, gating, and adaptive optimization.
These tests connect the failure to a weak training signal.

GLoRa measures weight gradients in the best-performing systems.
The main paper plots first-layer gradients across training epochs, and the appendix reports similar behaviour for other layers.
The gradients remain stable at magnitudes well above zero.
The systems also use common techniques against vanishing gradients, including adaptive optimization, initialization, gradient clipping, ReLU activation, and normalization \cite{zhou2025glora}.

These observations weigh against a simple vanishing-gradient account of the tested GLoRa failures.
If a disappearing backward signal were the main problem, the early-layer gradients should show the corresponding decay towards zero.
Instead, the measured gradients remain nonzero even though the systems still fail at larger dependency lengths.

The diagnostic has a clear limit.
Stable weight gradients show that training signals exist, but they do not show that those gradients point towards the intended solution.
A model can receive gradients and still learn a poor rule, and gradients can be large for parameters that do not help preserve the source information.
The measurements therefore narrow the explanation without identifying the positive mechanism behind the failure.
For the inspected systems and layers, they do not support the claim that vanishing gradients account for the observed degradation.

\section{How the Explanations Interact}

Over-smoothing, over-squashing, and vanishing gradients describe different traces within the same learned system.
Message passing defines a forward computation from the source information to the target node representation, while training defines a backward computation from the loss to earlier parameters.
The mechanisms can be separated analytically without being mutually exclusive in a graph neural network.
GLoRa therefore interprets architectural gains through the traces they affect rather than through category labels alone.

Over-smoothing and over-squashing can reinforce each other.
When each layer mixes many messages, the target node representation may both lose differences between nodes and discard details from a particular source node.
The relevant source information can then become unrecoverable even though the node representations have not all collapsed to the same value.
Increasing representation width may not help if repeated mixing still removes distinctions, just as preserving distinctions may not help when a narrow channel still compresses too much relevant information.

Vanishing gradients can interact with both forward mechanisms.
If gradients become too small in early message-passing layers, the model may never learn transformations that resist over-smoothing or prioritise source information when a bottleneck is unavoidable.
Conversely, healthy gradient magnitudes do not guarantee success if the forward computation has already destroyed the source information.
The optimizer can update the parameters without finding a computation that keeps the right information available at the target node.

Architectural changes can also affect several traces at once.
A residual connection may improve gradient flow while preserving earlier node representations, and normalization may stabilize training while changing how strongly representations mix.
A rewiring method may reduce over-squashing while shortening the effective dependency length $d$.
A gated message-passing system may help because it controls which messages are propagated rather than because it belongs to a single explanation category.
The best-performing systems in the main GLoRa experiments use gated edges, which suggests that controlled message propagation may be useful without identifying a final mechanism \cite{zhou2025glora}.

These overlapping effects make an intervention alone insufficient for causal identification.
An improvement from residual connections could reflect better gradient flow, less representational collapse, easier optimization, or a changed inductive bias.
Likewise, an improvement from rewiring could reflect reduced bottlenecks, a shorter effective dependency length, or another change to the task.
GLoRa therefore asks which trace is present in a failing run: collapsed node representations, a bottleneck in the directed graph construction, or gradients that vanish during training.

\section{What the Diagnostics Leave Open}

Mechanism-level diagnostics provide asymmetric evidence.
Finding a predicted trace can support a candidate explanation, although further evidence may still be needed to show that the trace caused the failure.
Not finding that trace weighs against the tested form of the explanation but does not establish a universal exclusion.
The accuracy drop serves as the common symptom from which these distinct tests begin.

The same distinction applies when comparing systems.
If a method designed to reduce over-smoothing performs better than a vanilla GNN at larger $d$, the result shows that the method is useful but not that over-smoothing caused the baseline failure.
The method may also change optimization, effective depth, normalization, parameter count, or message combination.
Similarly, a gain from rewiring may reflect reduced over-squashing, a shorter effective dependency length, or another change in the computation.

GLoRa applies one test to each proposed mechanism.
It checks final target node representations for the collapse predicted by over-smoothing, the directed construction for the path growth underlying the tested over-squashing account, and gradients in the inspected layers for decay during training \cite{zhou2025glora}.
In the main setting, the measured traces do not support the simple forms of these explanations.
This is stronger than observing inaccuracy, but weaker than identifying the true cause.

Several explanations therefore remain open.
The model may not learn the intended algorithmic rule, its message-passing inductive bias may not favour the required composition, or optimization may find a shortcut that works for shorter dependencies but does not extrapolate.
The source information may also be transformed into a representation that remains variable but no longer supports the label prediction.
These possibilities require further diagnostics and cannot be distinguished from the accuracy curve alone.

\section{The Role of GLoRa in the Explanation}

GLoRa has two related roles in this thesis.
As a benchmark, it separates general task performance from evidence that a system learned a dependency of length $d$.
Its construction is designed so that fitting enough examples requires the intended long-range dependency while that function remains expressible by standard GNN-based systems \cite{zhou2025glora,barcelo2020logical}.
As a diagnostic setting, it then asks why systems that can express the dependency fail to learn it reliably.

The benchmark construction makes the failure interpretable without explaining it by itself.
A failure at larger $d$ shows that a system did not learn the required dependency reliably.
Determining whether the reason is representation collapse, information compression, weak gradients, or another mechanism requires the separate diagnostic evidence developed in this chapter.

That evidence supports a restrained conclusion.
For the systems, layers, and directed construction that the paper inspects, the diagnostics do not support attributing the observed degradation to over-smoothing as measured by final representation collapse, the tested directed-path form of over-squashing, or vanishing weight gradients.
The claim goes beyond reporting low accuracy but stops short of identifying the true cause.

This distinction gives the three mechanisms their proper role in the thesis.
They remain central risks in deep message passing and useful ways to organise the state of the art.
GLoRa shows why they should be treated as diagnoses only when their predicted traces are present.
Understanding long-range failure requires both benchmarks that control dependency length $d$ and diagnostics that connect the observed failure to a mechanism.
