\chapter{Explanations of Long-Range Failure}

Message passing gives graph neural networks a simple way to use graph structure.
At each layer, a node updates its node representation from its previous-layer representation and from messages sent by neighbouring nodes.
After one layer, the target node can use information from its immediate neighbours.
After two layers, it can use information from nodes two hops away.
In the idealized picture, $d$ layers are enough for a source node at graph distance $d$ to affect the target node.

This idealized picture is useful, but reachability is not the same as learning.
A signal may be reachable by message passing without being used by the trained model.
The model must preserve the right information as message passing proceeds across successive layers.
It must have enough capacity to keep the relevant source information separate from irrelevant information.
It must also receive gradients that make the earlier layers learn the transformations needed for the final prediction.
When these conditions fail, accuracy can drop as the dependency length $d$ increases.

The literature often explains this drop through three phenomena: over-smoothing, over-squashing, and vanishing gradients \cite{li2018deeper,alon2021bottleneck,glorot2010difficulty}.
They are useful explanations because each names a concrete mechanism.
Over-smoothing says that node representations become too similar.
Over-squashing says that too much information is compressed into a fixed-size node representation.
Vanishing gradients say that the training signal becomes too small to teach early layers what to preserve.
Each mechanism is plausible in a deep message-passing model, and each has motivated architectural changes in graph learning \cite{zhou2025glora}.

This chapter treats these mechanisms as candidate explanations, not as automatic diagnoses.
The distinction matters for the thesis.
The included GLoRa paper studies tasks where the dependency length $d$ is controlled by construction.
The experiments show that many graph learning systems fail as $d$ grows.
This happens even though the intended dependency is expressible by standard message-passing systems and the number of layers is set large enough for the source information to affect the target node \cite{zhou2025glora}.
The paper then asks whether the observed failure can be attributed to over-smoothing, over-squashing, or vanishing gradients.
Its diagnostics do not support those explanations in the tested setting.
This does not make the three phenomena unimportant.
It shows that a long-range performance drop is a symptom whose cause must be checked rather than assumed.

\section{What a Candidate Explanation Must Explain}

A long-range task is not hard merely because two nodes are at large graph distance.
It is hard because the prediction at the target node depends on information from a source node that must be preserved across a sequence of message-passing layers.
The relevant dependency has two parts.
First, the graph must contain a path from the source to the target.
Second, the learned computation must use the source information through that path.
The dependency length $d$ measures the graph distance involved, but it does not by itself describe the learning mechanism.

For a candidate explanation to account for long-range failure, it should make a prediction about what goes wrong inside the model.
An explanation should not only say that accuracy is low.
It should say what internal quantity changes as $d$ increases and why that change makes the target node unable to use the source node.
For over-smoothing, the expected internal change is convergence of node representations.
For over-squashing, it is loss of relevant information when many signals must be compressed through a narrow part of the graph or a fixed-size node representation.
For vanishing gradients, it is a training signal that becomes too small in the layers that first process the source information.

This requirement matters because several facts change at the same time when $d$ increases.
The source node is at larger graph distance from the target node.
The model usually needs more message-passing layers.
The number of intermediate message-passing steps grows.
The distribution of messages at the target node can change.
The optimization landscape can change as the computation becomes deeper.
An accuracy curve alone cannot separate these effects.
It shows that the model failed to learn the benchmark well at a particular dependency length, but it does not identify which mechanism produced the failure.

The GLoRa paper uses this diagnostic view.
It first constructs benchmarks where the intended solution requires a dependency of length $d$.
It then evaluates systems on increasing values of $d$.
Finally, it checks whether the standard explanations leave the traces they should leave if they were the reason for the drop \cite{zhou2025glora}.
This structure is a useful model for the rest of the thesis.
It does not deny the value of the standard explanations.
It connects each explanation to evidence.

\section{Over-Smoothing}

Over-smoothing is a representational failure.
It occurs when node representations become increasingly similar as message passing goes deeper.
The original intuition is straightforward.
Many graph neural networks update a node by mixing its current node representation with information from its neighbours.
Repeated mixing can make different nodes look alike.
If the process continues for many layers, the model can lose the differences that it needs for node classification \cite{li2018deeper}.

In a long-range dependency task, over-smoothing is a natural candidate explanation.
To use a source node at distance $d$, the target node often needs information to pass through roughly $d$ message-passing layers.
Adding layers gives the source information enough message-passing steps to affect the target node.
At the same time, adding layers also gives the network more opportunities to mix node representations until they become hard to distinguish.
The same depth that makes communication possible can therefore make discrimination harder.

The mechanism can be described without special notation.
Suppose that two examples should receive different labels because the relevant source information differs along their paths.
If message passing preserves the distinction, their target node representations should differ.
The final classifier can then separate the labels.
If over-smoothing occurs, those final node representations move toward the same value.
The final classifier then sees nearly the same input for examples that require different outputs.
The model may still be deep enough in graph-distance terms, but the propagated information is no longer useful for the prediction.

The evidence for over-smoothing should therefore be evidence about node representations, not only evidence about accuracy.
A strong diagnostic would show that node representations collapse as the number of layers or the dependency length $d$ grows.
For node classification, the most direct place to inspect is the target node representation near the last layer.
If positive and negative examples require different predictions but their target node representations become nearly identical, that supports an over-smoothing explanation.
The evidence is stronger if this convergence happens before the classifier and if it becomes more severe for larger $d$.

Other evidence can also support the diagnosis.
One can measure the variance of node representations across nodes or across examples.
One can compare distances between target node representations for different labels.
One can inspect whether methods designed to prevent representational collapse restore both separation and accuracy.
The important point is that over-smoothing predicts a specific internal symptom.
The model should fail because the node representations that should remain different have become too similar.

GLoRa treats over-smoothing in this way.
The main experiments show that accuracy drops as $d$ increases for many systems.
That result alone is compatible with over-smoothing, but it does not prove it.
The paper therefore inspects the last-layer target node representations for the best-performing systems at a short dependency length where accuracy is perfect and at a longer dependency length where accuracy is close to random guessing.
At the short dependency length, the target node representations for the two labels are clearly separated.
At the longer dependency length, they are more mixed, as expected from the poor accuracy.
However, they do not collapse to a single value, and their standard deviation remains substantial \cite{zhou2025glora}.

This diagnostic result narrows the claim.
It does not show that over-smoothing never occurs in graph neural networks.
It does not show that over-smoothing is irrelevant to all long-range graph tasks.
It shows that, in the tested GLoRa setting and for the inspected systems, the observed accuracy drop is not accompanied by the representational convergence that an over-smoothing explanation would predict.
The model fails, but the final target node representations have not become indistinguishable in the over-smoothing sense.

GLoRa therefore treats over-smoothing as a candidate explanation rather than a complete explanation.
The phenomenon is real and well motivated.
It explains one way that deep message passing can destroy task-relevant distinctions.
But the existence of a deep message-passing model and a large dependency length $d$ is not enough to infer over-smoothing.
One must check whether the node representations actually collapse in the failing runs.

\section{Over-Squashing}

Over-squashing is an information-compression failure.
It occurs when too much information must be compressed into a fixed-size node representation.
A message-passing model stores what it has learned about a node's neighbourhood in a vector of fixed dimension.
If many nodes at large graph distance can influence the target node, the model may need to encode many signals through a small number of intermediate nodes or edges.
Some of those signals can be lost before they reach the target node.

The term is especially natural on graphs with bottlenecks.
Consider a target node whose label depends on one source node among many nodes at large graph distance.
If all possible source signals must pass through a narrow path, then the node representation on that path must encode a large amount of information.
Increasing the dependency length $d$ can make this problem worse when the number of possible paths or relevant nodes at large graph distance grows quickly.
The target node may be reachable from the source node in graph-distance terms, but the path may not have enough representational capacity for the model to preserve the right signal.

This differs from over-smoothing.
In over-smoothing, the problem is that node representations become too similar after repeated mixing.
In over-squashing, the problem is that the model must pack too much distinct information into a bounded representation.
A model can suffer from over-squashing even if node representations do not all converge.
The target node representation may retain variation, but the specific source information needed for the label may be compressed away.

The evidence for over-squashing should therefore focus on bottlenecks and information compression.
A structural diagnostic asks whether many paths, or many possible placements of the relevant source node, must influence the target node through a small cut in the graph.
A representational diagnostic asks whether increasing the width of node representations or changing the graph to shorten congested paths improves the ability to use a source node at large graph distance.
A causal diagnostic asks whether interventions that reduce the bottleneck restore performance while leaving other parts of the task comparable.
The common thread is that the evidence should connect the failure to message-passing bottlenecks toward the target node.

Over-squashing has motivated methods that alter message passing or the graph itself.
Some approaches add, remove, or reweight edges so that message passing can use shorter or less congested paths.
Others use broader attention patterns, positional information, or rewiring rules that try to reduce the pressure on narrow graph cuts.
The GLoRa paper groups several evaluated systems according to whether they target over-squashing or related gradient-flow problems \cite{zhou2025glora}.
These methods are important because they test whether the bottleneck view can lead to better long-range learning.

GLoRa's main construction is designed so that over-squashing is not the natural explanation for the observed failure.
In the directed GLoRa graphs, each example has a bounded number of additional chains, at most $10$, and this bound does not grow with $d$.
As a result, the number of directed paths leading to the target node is small and independent of the dependency length.
The paper argues that this rules out the particular over-squashing story in which an exponential number of paths is compressed into the target node representation \cite{zhou2025glora}.

The directedness of the construction is important for this argument.
If the same chain were treated as undirected, message passing could use both edge directions.
Even a simple chain could then generate many walks that end at the target node as the number of layers grows.
In that setting, the bounded-path argument would no longer be available.
The paper explicitly notes this qualification when explaining why over-squashing is not the reason for the main directed GLoRa results \cite{zhou2025glora}.

This does not mean that over-squashing is irrelevant to all GLoRa-like settings or all graph learning tasks.
It means that the tested failure cannot be explained by the standard bottleneck account without further evidence.
The source node is at large graph distance from the target node, but distance is not the same as congestion.
If there are only a few paths and the relevant signal is intentionally simple, then a performance drop with larger $d$ needs another explanation.
The model may be failing to preserve the source information through repeated message-passing layers, to learn the right local rule, or to optimize a deep composition.
Those are different claims from over-squashing.

GLoRa therefore uses over-squashing as a candidate explanation with a clear prediction.
If over-squashing causes the drop, the graph construction should force many signals through a narrow representational channel, or methods that reduce such bottlenecks should remove the failure.
In the main directed benchmarks, the path structure does not match that prediction.
The observed failure remains, so over-squashing is not a complete explanation for those results.

\section{Vanishing Gradients}

Vanishing gradients are an optimization failure.
They occur when the gradient of the loss becomes very small as it is propagated backward through a deep computation.
In a message-passing graph neural network, a prediction at the target node may depend on earlier message-passing layers.
If the gradient reaching those early layers is close to zero, the model may not learn how to transform the source information before it is propagated toward the target node.

The mechanism is not specific to graphs.
Deep neural networks are trained by backpropagation, which uses the chain rule.
When many derivatives are multiplied together, their product can become very small.
If this happens consistently, early parameters receive weak updates.
The network may then train slowly or stop improving in the parts of the computation that matter for long-range dependencies \cite{glorot2010difficulty}.

Graphs add a message-passing interpretation to this familiar problem.
For a dependency of length $d$, the source information must be processed and propagated through a sequence of layers before it can affect the target node prediction.
The loss is computed at the output.
The gradient must then backpropagate through the classifier, through the target node updates, and through the intermediate message-passing layers.
If this backward signal decays with depth, the parameters that first handle the source information may learn too little.
The forward computation may have a path from the source node to the target node, but the training process may not teach the model to preserve source information along that path.

The evidence for vanishing gradients should be evidence about training dynamics.
A direct diagnostic measures gradient norms in early layers as the dependency length $d$ or the number of message-passing layers increases.
If the gradients at early layers shrink toward zero in the failing setting, and if this shrinkage is absent in successful shorter settings, the diagnosis becomes plausible.
One can also inspect whether techniques known to improve gradient flow restore both gradient magnitude and task accuracy.
Examples include residual connections, normalization, careful initialization, gating, and adaptive optimization.
The key point is that the failure should be tied to a weak training signal, not merely to low final accuracy.

GLoRa tests this explanation by measuring weight gradients in the best-performing systems.
The main paper plots first-layer gradients across training epochs for the systems it inspects.
The gradients remain stable and have magnitudes well above zero.
The appendix reports similar behaviour for other layers.
The systems also use common techniques against vanishing gradients, including adaptive optimization, initialization, gradient clipping, ReLU activation, and normalization \cite{zhou2025glora}.

These observations make the vanishing-gradient explanation less convincing for the tested GLoRa failures.
If the main problem were that the backward signal disappeared, the early-layer gradients should show that disappearance.
Instead, the measured gradients remain nonzero.
The systems still fail at larger dependency lengths, which means the cause must be more specific than a simple vanishing-gradient account.

At the same time, the diagnostic should be read carefully.
Stable weight gradients show that training signals exist, but they do not prove that the gradients point toward the right solution.
A model can receive gradients and still learn a poor rule.
Gradients can also be large for parameters that do not preserve the source information.
Thus, the absence of vanishing gradients rules out one broad optimization story, but it does not identify the positive mechanism behind the failure.
It narrows the explanation rather than finishing it.

This is again why the thesis treats vanishing gradients as a candidate explanation.
The phenomenon is a genuine risk in deep models, and dependency length $d$ often forces greater depth.
But a failure at larger $d$ should not be labeled as vanishing gradients unless the training dynamics show the expected gradient collapse.
In the GLoRa experiments, they do not.

\section{How the Explanations Interact}

The three explanations are easiest to describe separately, but they can interact in real models.
A message-passing system has one forward computation and one training process.
Over-smoothing, over-squashing, and vanishing gradients name different ways that this system can fail.
They are not mutually exclusive categories.

Over-smoothing and over-squashing can reinforce each other.
When many messages are mixed at each layer, the target node representation may both lose differences between nodes and discard details from a particular source node.
The result can look like a smooth representation space in which the relevant source information is no longer recoverable.
In such a case, a method that only increases representation width may not help if repeated mixing still washes out distinctions.
Likewise, a method that only preserves differences between nodes may not help if the graph still forces many signals to be compressed through a narrow path.

Vanishing gradients can also interact with the two forward failures.
If gradients become too small in early layers, the model may never learn transformations that resist over-smoothing.
It may also fail to learn which information should be prioritized when a bottleneck is unavoidable.
Conversely, if forward message passing already destroys the source information, then healthy gradient magnitudes do not guarantee success.
The optimizer can update parameters, but it may still not find a computation that keeps the right information available at the target node.

These interactions matter for interpreting architectures.
A residual connection may help gradient flow and also preserve earlier node representations.
A normalization method may stabilize training and also change how strongly node representations mix.
A rewiring method may reduce over-squashing and also shorten the effective dependency length $d$.
A gated message-passing system may help because it controls which messages are propagated, not because it fits neatly into only one of the three explanation categories.
The GLoRa paper observes that the best-performing systems in the main experiments use gated edges, which suggests that controlled message propagation may be useful, but it does not by itself identify a final mechanism \cite{zhou2025glora}.

The interaction between explanations is one reason that diagnostic evidence must be precise.
If a model improves after adding residual connections, the improvement could come from better gradient flow, less representational collapse, easier optimization, or a changed inductive bias.
If a rewiring method improves performance, the improvement could come from reducing bottlenecks, shortening paths, or making the benchmark easier in another way.
Architectural success is valuable, but it is not the same as causal identification.
The mechanism still needs to be tested.

\section{Why a Drop with Increasing Dependency Length Is Not a Diagnosis}

A performance drop with increasing dependency length $d$ is the starting observation, not the explanation.
It says that the learned function no longer fits the benchmark as the required source-to-target dependency becomes longer.
Several mechanisms can produce the same curve, and the curve alone does not identify which one occurred.

The problem is a form of non-identifiability.
When $d$ increases, the benchmark asks the model to use information across larger graph distances.
In many experiments, the number of message-passing layers also increases so that the receptive field is large enough.
The computation becomes deeper, the source information is processed by more intermediate message-passing layers, and the target node aggregates messages after more rounds of mixing.
Training must also optimize a longer chain of transformations.
If accuracy drops, any of these changes could be responsible.

Over-smoothing predicts one trace.
The target node representations for different labels should become too similar.
Over-squashing predicts another trace.
The graph or computation should force too many relevant signals to be compressed through a narrow channel.
Vanishing gradients predict a third trace.
The gradients needed to train early message-passing layers should shrink toward zero.
A single accuracy number has none of this information.
It is compatible with all three explanations and with other explanations as well.

The same caution applies when comparing systems.
Suppose a method designed to reduce over-smoothing performs better than a vanilla GNN at larger $d$.
That result suggests that the method is useful, but it does not prove that the vanilla model failed because of over-smoothing.
The method may also change optimization, effective depth, normalization, parameter count, or the way messages are combined.
Similarly, if a rewiring method helps, the reason may be over-squashing, but it may also be that the method has shortened the dependency length that the model actually needs to learn.

GLoRa's conclusion is therefore methodological.
The paper does not stop after showing that accuracy falls with increasing $d$.
It asks whether the usual explanations make predictions that are visible in the failing runs.
For over-smoothing, the paper checks whether the final target node representations collapse.
For over-squashing, it checks whether the directed construction creates the kind of path explosion required by the bottleneck story.
For vanishing gradients, it checks whether gradients in the inspected layers vanish during training \cite{zhou2025glora}.
In the main setting, the measured traces do not match these explanations.

This result prevents a common shortcut in interpretation.
It is tempting to see a long-range failure and immediately name one of the standard phenomena.
The name gives the result a familiar shape, but it can also hide the fact that the evidence has not been checked.
In the GLoRa experiments, the familiar names do not fully account for the observations.
The systems fail at larger $d$, but the measured node representations, graph construction, and gradients do not match the simple versions of the three explanations.

The right conclusion is not that the performance drop has no cause.
It is that these three broad accounts have not identified the cause.
The model may fail because it does not learn the intended algorithmic rule.
It may fail because the inductive bias of message passing does not favour the required composition.
It may fail because optimization finds a shortcut that works for shorter dependencies but does not extrapolate.
It may fail because the source information is transformed in a way that remains variable but is no longer useful for label prediction.
These possibilities require further diagnostics.
They cannot be read directly from the accuracy curve.

\section{The Role of GLoRa in the Explanation}

GLoRa is useful in this thesis because it separates two questions that are often blurred.
One question is whether a graph learning system performs well on a benchmark.
Another is whether that performance certifies learning a dependency of length $d$.
The benchmark is designed so that fitting enough examples requires using the intended long-range dependency, while the intended function remains expressible by standard GNN-based systems \cite{zhou2025glora,barcelo2020logical}.

This design makes failures easier to interpret, but it does not automatically explain them.
When a system fails on GLoRa at larger $d$, the benchmark tells us that the system did not learn the required dependency reliably.
It does not tell us whether the reason is representational collapse, information bottlenecking, weak gradients, or another mechanism.
The diagnostic part of the paper is essential because it turns the standard explanations into testable hypotheses.

The tests leave GLoRa with a restrained conclusion.
The diagnostics do not support attributing the observed degradation in the main experiments to over-smoothing, over-squashing, or vanishing gradients.
This claim is stronger than saying that the systems are inaccurate, but weaker than identifying the true cause.
It says that the common explanations do not match the evidence available in the tested setting.

This restrained conclusion is the one needed for the rest of the thesis.
Over-smoothing, over-squashing, and vanishing gradients remain central concepts in long-range graph learning.
They explain real risks in deep message passing and organize much of the state of the art.
GLoRa shows that they should be used as diagnoses only when their predicted traces are present.
The long-range problem is broader than any one of them.
Understanding it requires benchmarks that control the dependency length $d$ and diagnostics that connect failures to mechanisms.
